# Sistreamans – downloads

Installatiebestanden van Sistreamans. De app controleert hier zelf op updates (`latest.json` in de nieuwste release).

| Apparaat | Bestand |
|---|---|
| Google TV / Android | `Sistreamans-android.apk` |
| Windows | `Sistreamans-Setup.exe` |
| Mac | `Sistreamans-macos.zip` |

Nieuwste versie: **[Releases](../../releases/latest)**

Een nieuwe versie bouwen: tabblad **Actions → Nieuwe versie bouwen → Run workflow**.
